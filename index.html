Personal project · Oct 2026

AI fashion assistant for Messenger & Telegram

Customers chat in plain Vietnamese ("off-shoulder beach dress under 500k"). An AI agent searches the shop's live stock, checks product photos when needed, sends product cards and takes orders. The shop owner runs everything from Google Sheets. Fully serverless, on free tiers.

Features

What the bot does

Natural-language product search

Understands price, color, type and negations ("not black", "under 500k") and returns only items in stock.

DeepSeekText-to-SQLD1

Style advice from vague needs

Turns "hides the tummy" or "for a temple visit" into concrete cuts, then ranks items by meaning.

Gemini embeddingsVector search

Looks at product photos

Checks images in batches of 16 when attributes are not enough to decide fit or style.

VisionR2

Size & shop questions

Suggests a size from height and weight, answers shipping, returns and opening hours.

D1Sheets

Product cards in chat

Photo, price, sizes and action buttons on both channels, with a typing indicator while it works.

MessengerTelegram

Ordering in chat

Drafts the order, customer confirms with one tap. Look up and cancel orders too. Cash on delivery.

PostbackWorkersD1

Catalog managed in Google Sheets

Dropdowns, auto-generated product codes, invalid cells highlighted with a note, sync log.

SheetsApps Script

Orders back in the sheet

New and cancelled orders land in an Orders tab with the chat transcript, and the shop gets an email.

Apps ScriptMailApp

Safety guards

Model SQL is read-only, internal tables are blocked, and any product code not found by a lookup is rejected.

WorkersSQL sandbox
Tech stack

Serverless end to end, on free tiers

Serverless runtime

  • Cloudflare WorkersTypeScript backend on the edge
  • Cloudflare QueuesChat messages and background jobs
  • Cron TriggersScheduled catalog sync
  • WranglerLocal dev, migrations, secrets, deploy

Webhooks & channels

  • Messenger PlatformWebhook, Send API, postback buttons
  • Telegram Bot APIWebhook with secret token, inline buttons
  • HMAC SHA-256Verifies every Meta request (Web Crypto)
  • Admin REST APIImport, orders, test chat; key-protected

Data & search

  • Cloudflare D1SQLite: products, stock, sizes, vectors, orders
  • Workers KVChat history, expires after 7 days
  • Cloudflare R2Product image copies (optional)
  • Hybrid retrievalSQL filter + in-memory cosine ranking

AI

  • DeepSeek V4.1 FlashAgent reasoning, tool calling, vision
  • GeminiText and image embeddings, fallback model
  • Workers AIFast pre-routing before the agent
  • Shared LLM layerOne interface for Gemini and OpenAI-style APIs

Back office

  • Google SheetsSource of truth for catalog and orders
  • Google Apps ScriptBot menu, sync, 5-minute triggers
  • Data validation & formattingDropdowns, stock and status colors
  • MailAppNew-order emails

Testing

  • Vitest74 tests inside the Workers runtime
  • Python eval suiteTop-3 hit, precision, hallucination, latency
